# レビュー分析アプリ

## 概要

価格.comのレビューを取得し、AIによる感情分析（ポジティブ・ネガティブ判定）を行うアプリです。

## 使用技術

* Python
* Streamlit
* Hugging Face Transformers
* pandas
* BeautifulSoup
* requests

## 主な機能

* レビュー取得
* 感情分析
* ネガティブレビュー抽出

## 開発背景

2023年にキカガク受講時に作成したレビュー分析アプリをベースに、生成AIを活用して再構築しました。

## 今後の改善予定

* 複数ページ対応
